## Why
La app necesita un tema claro y oscuro para mejorar la experiencia visual y adaptarse a la preferencia del sistema operativo.

## What Changes
- Añadir soporte para tema claro y oscuro.
- Detectar la preferencia del sistema mediante `prefers-color-scheme`.
- Permitir override manual desde la interfaz.
- Persistir la elección en el navegador para mantenerla entre sesiones.

## Impact
- Affected specs: none
- Affected code: UI shell, navbar, estilos globales
